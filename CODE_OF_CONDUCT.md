# Code of Conduct

OpenMail contributors are expected to be respectful, specific, and constructive. Critique code, decisions, and behavior without personal attacks, harassment, discrimination, or intimidation.

Use welcoming language, explain disagreements with evidence, respect different experience levels, and protect private mailbox data. Harassment, threats, discriminatory language, deliberate exposure of private data, and repeated disruptive behavior are not acceptable.

Project maintainers may remove comments, close discussions, reject contributions, or restrict participation when behavior violates this code. Reports should be made privately through the security reporting channel or to the repository maintainers.
